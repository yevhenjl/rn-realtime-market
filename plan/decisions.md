## D-002 · Владение кодом: жёсткое и мягкое — 2026-11-12

- Контекст: `AGENTS.md` закрепляет ядро за учеником; курс помечает «сам» ещё и шаги вне ядра (форматтеры, строка списка, свечи, жесты).
- Решение: ядро — 🧑 (агент не пишет никогда); «сам» вне ядра — 🧑* (агент пишет только при явном делегировании); «готовое» из курса вне ядра — 🤖. Готовый код курса внутри путей ядра (`src/realtime/client.ts`, `FakeSocket`, тесты-спецификации ядра) переносит ученик.
- Почему: сохраняет учебную ценность и правило `AGENTS.md`, агент не простаивает.
- Откат: перевести задачу в 🤖 по слову ученика, отметить в журнале progress.
- **Обновление 2026-11-12:** пользователь делегировал агенту форматтеры (S6.1), строку списка (S6.3), свечи (S7.1), жесты (S7.3) → 🤖. Граница сохранена: если для них нужна чистая функция в `src/chart/**` (ядро), её пишет ученик; агент использует её API. S4.7 (`useWatchlistStream`) остаётся 🧑*.

## D-009 · Dev build через EAS — 2026-11-12

- Контекст: пользователь попросил собрать dev build в EAS, чтобы установить APK на телефон.
- Решение: `eas build -p android --profile development --non-interactive --no-wait`; профиль уже есть в `eas.json` (APK, только arm64-v8a). Локальная Gradle-сборка остановлена.
- Почему: на Mac нет AVD и не подключён телефон; облако не зависит от локального SDK 37.
- Откат: локально `bunx expo prebuild --clean` + `bun run android` при подключённом устройстве.

## D-011 · Патч-обновления Expo 58 для зелёного CI — 2026-11-12

- Контекст: CI падал на `bunx expo install --check` (было и на `main`).
- Решение: `bunx expo install --fix` в ветке PR #1: патчи Expo 58, `react-native` 0.88.0 → 0.88.1, `safe-area-context` 5.10 → 5.11, `screens` 4.30.1, `jest-expo` 58.0.14; peer `@react-native/jest-preset` → 0.88.1 через `bun update`, без добавления в `package.json`. `expo install --fix` добавил плагин `expo-status-bar` в `app.json`.
- Почему: в рамках закреплённого стека (Expo 58, RN 0.88); CI — обязательный сигнал.
- Последствия: нативное изменение → нужен новый development build; EAS-сборка из D-009 собрана на старых версиях.
- Откат: `git revert` коммита; CI снова упадёт.
